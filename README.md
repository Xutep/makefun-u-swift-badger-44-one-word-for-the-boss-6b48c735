One word for the boss: **goldfish**.

A boss with the memory of a goldfish forgets, within seconds, what they
asked for, what they promised, and what they told you yesterday — and then
asks again as if it were the first time. Every office, kitchen and
warehouse has met one.

## Run it

```sh
python3 main.py
```

The program writes exactly one word, `goldfish` (8 characters, no trailing
newline), to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write
elsewhere when testing locally.
